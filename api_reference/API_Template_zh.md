> **如何使用本模板**
> - API 参考文档面向**构建该服务的团队之外的人**：App 和网页开发者、其他团队、合作伙伴和 QA。它说明 API 做什么、怎么调用。它是怎么构建的，属于 SDD。
> - **生成它，不要重新手打。**OpenAPI 文件是唯一事实来源。端点表、请求和响应的 schema、示例都应当来自它。只有工具无法知道的内容才手写：概述、快速开始、规则、重试建议和变更日志。

> - 为从未见过你代码的人来写。不要提及服务内部的队列、表、内部服务或重试时间。
> - **在修改 API 的同一次变更中**更新本文档。参考文档只有保持准确才有用。
